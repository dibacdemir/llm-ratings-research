# data/

One folder per dataset, grouped by the level of language it probes. This is
the source of truth: edit here, nowhere else.

    data/<level>/<task>/
        instruction.txt     the wording the model is given, <<{...}>> where the stimulus goes
        ratings.csv         unit,mean,std,n,individual_ratings
        metadata.json       source, size, scale, level, provenance, human reliability
    data/INDEX.csv          one row per dataset, generated by pipeline/build_index.py

## Levels

`subword`, `lexical_semantics` (affective / perceptual_motor / conceptual),
`syntax`, `sentence_semantics` (plausibility / affective / conceptual_content),
`pragmatics`, `discourse`, and `other` for rating variables that are
linguistic but not a level (age of acquisition, familiarity, frequency, cloze).
Sublevels are in `metadata.json`, not in the path.

The level of every dataset was decided by Andrea in `audit/dataset_levels.csv`
(`decided_by`, `rationale`, and whether a blind second pass agreed);
`metadata.json` carries the same three fields. To move a dataset, move its
folder and update both files.

## Where it came from

The folders were copied on 2026-09-03 from the three trees the collaborators
built — published norms, TedLab surveyor, TedLab MTurk — now under `archive/`.
`metadata.json`'s `original` field records the path each file came from, and
`provenance` what the collections' own indexes said about it (question wording
reconstructed or verbatim, participants, fillers). `merged_from` lists the
batches Andrea pooled into one dataset on 2026-08-22.

## metadata.json fields

| field | meaning |
|---|---|
| `task`, `source`, `level`, `sublevel`, `language` | identity |
| `level_decided_by`, `level_rationale`, `level_blind_check_agrees` | from audit/dataset_levels.csv |
| `n_items`, `n_ratings`, `ratings_per_item_{min,median,max}`, `has_individual_ratings` | size |
| `scale`, `placeholder`, `unit_non_ascii` | what the prompt needs |
| `human_reliability` | split-half reliability of the raters, Spearman-Brown corrected (`pearson_sb`, `spearman_sb`); `null` when only means exist. `pipeline/human_reliability.py` |
| `merged_from`, `provenance`, `original` | history |
